# Contributing

Delta MCP is a free app, and its source code is not public. This repository only presents it, so there is no code to change here. There are still good ways to help.

- **Give it a ⭐.** Click **Star** at the top right of the repository. It is the simplest way to support Delta MCP, and it helps other people who use MCP find it.
- **Tell us what you need.** In [Discussions](https://github.com/mcpdelta/mcpdelta/discussions/new?category=ideas), say what you would want your AI to do in your tools, and what worries you about letting it.
- **Ask a question.** In [Q&A](https://github.com/mcpdelta/mcpdelta/discussions/new?category=q-a). The usual answers are in the [FAQ](https://www.mcpdelta.com/docs/faq).
- **Read it in your language.** The site and this README exist in 15 languages. If a sentence reads wrong, tell us in [General](https://github.com/mcpdelta/mcpdelta/discussions/new?category=general): the language, the page, and what would be better.
- **Report a problem on a page.** Open an [issue](https://github.com/mcpdelta/mcpdelta/issues/new/choose) for a wrong fact or a broken link on the website or in the docs.
- **Follow the launch.** **Watch → Custom → Releases** on this repository, or [RSS](https://www.mcpdelta.com/feed.xml): no email address needed.

Pull requests are limited to collaborators: the README files are built from the website's texts, so a change to a sentence is made at its source. A security problem goes to [contact@mcpdelta.com](mailto:contact@mcpdelta.com), privately (see [SECURITY.md](SECURITY.md)). Please leave secrets and other people's data out of everything you post.

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
