## پہلے فیصلہ کریں۔ بعد میں دیکھیں۔ کالعدم کریں۔

1. **آپ پہلے فیصلہ کرتے ہیں۔** ہر ٹول کے لیے طے کریں کہ آپ کا اے آئی خود کیا کر سکتا ہے: صرف پڑھے، حذف کرنے یا بھیجنے سے پہلے پوچھے، یا ہر بار پوچھے۔ جب وہ پوچھتا ہے، تو آپ ہر تبدیلی پہلے اور بعد میں دیکھتے ہیں۔
2. **آپ دیکھتے ہیں کہ کیا ہوا۔** ہر تبدیلی اپنی پہلی اور بعد کی حالت کے ساتھ ریکارڈ ہوتی ہے۔ یہ ریکارڈ Delta MCP لکھتا ہے، آپ کا اے آئی نہیں۔ جہاں ممکن ہو، Delta MCP ٹول کے اندر نتیجہ جانچتا ہے، اور اگر کنکشن ٹوٹ جائے، تو دوبارہ کچھ بھی کرنے سے پہلے جانچتا ہے۔
3. **آپ کالعدم کر سکتے ہیں۔** Undo وہ واپس کرتا ہے جو واپس ہو سکتا ہے، اور کلک کرنے سے پہلے ہی بتا دیتا ہے کہ کیا واپس نہیں ہو سکتا، جیسے پہلے سے بھیجا گیا پیغام۔

## آپ کے اے آئی کے کام کے لیے Ctrl+Z۔

ہر کام ہر تبدیلی کو پہلے اور بعد میں دکھاتا ہے۔ اسے فوراً کالعدم کریں، اور بعض صورتوں میں بعد میں بھی، خود آپ یا آپ کا اے آئی۔

- **پہلے اور بعد میں۔** ہر تبدیلی دکھائی جاتی ہے، جیسی وہ پہلے تھی اور جیسی اب ہے، جہاں تک ممکن ہو سروس سے دوبارہ پڑھ کر۔
- **ایک قدم یا پورا کام۔** آپ کا اے آئی لکھتا ہے کہ ہر قدم کو کالعدم کیسے کرنا ہے۔ اگر بعد کا کوئی قدم ناکام ہو جائے، یا آپ Undo پر کلک کریں، تو یہ کالعدم کرنے والے قدم الٹی ترتیب میں چلتے ہیں۔
- **جو واپس نہ آ سکے، اس کے بارے میں صاف بات۔** کلک کرنے سے پہلے آپ دیکھ لیتے ہیں کہ کیا پہلے جیسا کر دیا جائے گا اور کیا نہیں ہو سکے گا، جیسے پہلے سے بھیجا گیا پیغام۔ Delta MCP ثبوت کے بغیر کبھی نہیں کہتا کہ سب کچھ کالعدم ہو گیا ہے۔

## بار بار ہونے والے کام آٹومیٹ کریں۔

ایک بار طے کریں۔ Delta MCP اسے ہر روز، ہفتے کے دنوں میں، ہر پیر کو، یا ہر گھنٹے چلاتا ہے، بہت کم لاگت پر، اور آپ کا اے آئی صرف تب مداخلت کرتا ہے جب کام کو سوچ کی ضرورت ہو۔

- **رپورٹس اور روٹین کے کام۔** گزشتہ رات کے Grafana لاگز کا تجزیہ کریں اور ٹیم کو رپورٹ بھیجیں۔ ہر صبح مارکیٹ پر نظر رکھیں۔ ہر جمعے مکمل ہونے والے ٹکٹ بند کریں۔
- **مفت، یا اپنے اے آئی کے ساتھ۔** Delta MCP اسے مفت چلاتا ہے، بغیر اے آئی کے۔ تجزیہ درکار ہو تو آپ کا اے آئی طے شدہ وقت پر اسے سنبھالتا ہے، پھر رپورٹ لکھتا ہے، ای میل بھیجتا ہے، یا نتائج پر عمل کرتا ہے۔
- **اپنے اے آئی سے بنانے کو کہیں۔** اپنے اے آئی کو بتائیں کہ کیا آٹومیٹ کرنا ہے، وہ Delta MCP میں بنا دیتا ہے۔ آپ ٹیسٹ کریں، پھر ایک بار دستخط کریں۔ دو ناکامیوں کے بعد یہ رک کر بتاتا ہے۔
