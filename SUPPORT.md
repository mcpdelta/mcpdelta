# Support

- **A question about Delta MCP:** [ask it in Discussions](https://github.com/mcpdelta/mcpdelta/discussions/new?category=q-a). The usual answers are in the [FAQ](https://www.mcpdelta.com/docs/faq) and the [docs](https://www.mcpdelta.com/docs).
- **An idea:** [share it in Discussions](https://github.com/mcpdelta/mcpdelta/discussions/new?category=ideas).
- **A problem on the website or in the docs:** [open an issue](https://github.com/mcpdelta/mcpdelta/issues/new/choose).
- **A security problem:** write to [contact@mcpdelta.com](mailto:contact@mcpdelta.com), privately. See [SECURITY.md](SECURITY.md).

Delta MCP is not out yet. [Follow the launch](https://www.mcpdelta.com/download), and please leave secrets and other people's data out of everything you post.
